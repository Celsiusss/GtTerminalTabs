> [!WARNING]

## Features

- Click a tab to filter, again to clear. Right-click for show/edit/remove.
- Active category shown as a badge in the search box (click to clear); also filters NEI when AE2 syncs with NEI.
- Editor (gear button): add, remove, rename, reorder; drag an NEI item onto the slot to set an icon.
- Optional "Always use prefixes", globally or per tab.

## Requirements

GTNH 2.8.4+ (AE2 rv3-beta-695-GTNH+, NEI 2.8.44-GTNH+, GTNHMixins or UniMixins). Client only.
